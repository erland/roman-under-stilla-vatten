# Amazon KDP-publiceringspaket

Detta paket samlar praktiskt underlag för publicering av *Under stilla vatten* som Kindle eBook via Amazon KDP.

## Rekommenderade filer att använda vid uppladdning

- Manus/ebook-fil: `exports/Under_stilla_vatten_Erland_Lindmark.epub`
- KDP-omslag: `exports/omslag_under_stilla_vatten_kdp.jpg`
- Metadata: `exports/amazon_kdp/metadata_amazon_kdp.md`
- Beskrivning: `exports/amazon_kdp/beskrivningar_amazon_kdp.md`
- Kategorier, nyckelord och pris: `exports/amazon_kdp/kategori_nyckelord_prisforslag.md`
- Checklista: `exports/amazon_kdp/publiceringschecklista.md`

## Status

- Skapad: 2026-05-28
- EPUB: Finns och har tidigare passerat EPUBCheck enligt användarens test.
- KDP-omslag: Skapat som JPEG, 1600 × 2560 px, RGB, 300 dpi.
- Kapiteltexter: Oförändrade i detta paket.

## Viktigt

Testa EPUB-filen i Kindle Previewer innan publicering, eftersom Amazon konverterar EPUB till Kindle-format vid uppladdning.
