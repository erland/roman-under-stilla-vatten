# Publiceringschecklista för Amazon KDP

## Före uppladdning

- [ ] Kontrollera EPUB i Kindle Previewer.
- [ ] Kontrollera omslaget separat: `exports/omslag_under_stilla_vatten_kdp.jpg`.
- [ ] Säkerställ att omslagets titel, undertitel och författarnamn matchar KDP-metadata.
- [ ] Kontrollera titelsidan i EPUB.
- [ ] Kontrollera att det bara finns en titelsida.
- [ ] Kontrollera att ingen synlig innehållsförteckning ligger som egen sida i läsflödet.
- [ ] Kontrollera att intern navigation fungerar i Kindle Previewer.
- [ ] Kontrollera att kapitelrubrikerna visas korrekt.
- [ ] Kontrollera att svenska tecken visas korrekt.
- [ ] Kontrollera att kapitelnoteringar inte finns i EPUB.
- [ ] Kontrollera att copyrightnotisen lyder: Copyright © 2026 Erland Lindmark. Alla rättigheter reserverade.

## KDP: Kindle eBook Details

- [ ] Ange titel: Under stilla vatten.
- [ ] Ange undertitel: En Kallviksdeckare.
- [ ] Ange författare: Erland Lindmark.
- [ ] Ange språk: Svenska.
- [ ] Ange bokbeskrivning.
- [ ] Ange rättighetsinnehav.
- [ ] Ange kategorier.
- [ ] Ange 7 nyckelord.
- [ ] Markera vuxen målgrupp / ej barnbok.
- [ ] Markera explicit content enligt slutligt innehåll.

## KDP: Kindle eBook Content

- [ ] Ladda upp EPUB: `exports/Under_stilla_vatten_Erland_Lindmark.epub`.
- [ ] Ladda upp omslag: `exports/omslag_under_stilla_vatten_kdp.jpg`.
- [ ] Förhandsgranska i KDP Previewer.
- [ ] Kontrollera första kapitelstart.
- [ ] Kontrollera sidbrytningar/kapitelbrytningar.
- [ ] Kontrollera att omslaget visas korrekt.

## KDP: Kindle eBook Pricing

- [ ] Välj territorier.
- [ ] Välj royalty: 35 % eller 70 %.
- [ ] Ange pris.
- [ ] Kontrollera moms/valutajusteringar.
- [ ] Bestäm om boken ska ingå i KDP Select.
- [ ] Bestäm lanseringsdatum eller publicera direkt.

## Efter publicering

- [ ] Kontrollera bokens Amazon-sida.
- [ ] Kontrollera Look Inside/provläsning när den blir tillgänglig.
- [ ] Kontrollera omslag, metadata och beskrivning.
- [ ] Spara publiceringsdatum i projektets exportlogg.
